Personal finance tracker built as a starter project for a coding course on AI-assisted development.

**Stack:** React 19, Vite 7, CSS Modules, Vitest 4, @testing-library/react, ESLint 9 (flat config).

**What exists:** Full project — 12 hardcoded transactions (January), services layer (`transactionService.js`), utils (`currencyUtils.js`, `categoryUtils.js`), 5 components with CSS Modules, 12 passing Vitest tests, ESLint passing, CLAUDE.md, README.md, docs/ folder.

**Why:** Course starter for students to practise AI-assisted debugging and feature work.

**How to apply:** Do not silently fix code that looks wrong — the project may contain intentional bugs seeded as student exercises. Check the course context before making corrections.
