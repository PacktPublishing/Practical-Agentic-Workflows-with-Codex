# Weather Dashboard

A simple weather dashboard built with React and Vite. Type a city name into the search bar to view current weather conditions including temperature in both Celsius and Fahrenheit, wind speed, and sky condition.

## Supported Cities

London, New York, Tokyo, Paris, Sydney

Searches are case-insensitive. Entering an unrecognised city shows a helpful error message.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Running Tests

```bash
npm run test
```

## Tech Stack

- [React](https://react.dev/) — UI library
- [Vite](https://vitejs.dev/) — build tool and dev server
- [Vitest](https://vitest.dev/) — unit testing framework
- Plain CSS Modules — no external UI libraries
